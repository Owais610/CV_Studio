# Bundled fonts

CV Studio bundles the regular, bold, oblique and bold oblique faces of
DejaVu Sans so its PDFs keep the same typography on computers without Python
or separately installed fonts.

These unmodified font files and `LICENSE_DEJAVU` come from Matplotlib's
`mpl-data/fonts/ttf` distribution. DejaVu Sans is based on Bitstream Vera and
includes public-domain DejaVu additions. The included license permits
redistribution with applications; see `LICENSE_DEJAVU` for the full terms and
copyright notice.

Upstream project: <https://dejavu-fonts.github.io/>
